# Yong Hoon Cho — Personal Academic Website

Personal website for **Yong Hoon Cho**, hosted with GitHub Pages and designed as a lightweight static site using HTML and CSS.

## Site structure

- `index.html` — **Home**
  - Profile and current affiliation
  - Research interests
  - Contact information
  - Professional links

- `research.html` — **Research**
  - Job Market Paper
  - Working papers
  - Links to research PDFs

- `cv.html` — **Curriculum Vitae**
  - Full CV content displayed directly on the webpage
  - Download link for the PDF version of the CV

The primary navigation links are:

- Home

Research Interests and Contact remain on the Home page.

## Design

The site uses a responsive academic-style layout with:

- Times New Roman throughout
- Desktop and mobile-specific sizing
- A sidebar for profile information
- Responsive layout for mobile devices
- Direct PDF links for research papers
- A webpage-rendered CV with a downloadable PDF copy

## Domain and hosting

The website is intended to be hosted through **GitHub Pages** and served from:

`https://www.yongcho.com`

The domain is registered through Squarespace and points to GitHub Pages through DNS.

## Updating the site

When updating content:

1. Edit the appropriate HTML file.
2. Replace PDFs in the `files/` directory while keeping the same filenames when possible.
3. Replace `assets/profile.jpg` to update the profile photo.
4. Commit and push the changes to the GitHub repository.
5. GitHub Pages will publish the updated version automatically.
